# Secure Network Lab

🔗 **Dépôt :** [github.com/slimanebou/secure-network-lab](https://github.com/slimanebou/secure-network-lab)

Lab réseau sécurisé sur 4 VMs Debian 13 (VMware Workstation) : routeur-pare-feu iptables, DMZ web en HTTPS signée par une CA interne, administration uniquement par VPN WireGuard, supervision Zabbix/SNMP, analyse de trafic et script de diagnostic Bash.

**Stack :** `iptables` · `NAT/DNAT` · `WireGuard` · `Nginx` · `OpenSSL` · `dnsmasq` · `Zabbix` · `SNMP` · `tcpdump` · `Wireshark` · `Bash`
